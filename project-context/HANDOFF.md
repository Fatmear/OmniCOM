## Open Boundaries

- R-320 性能目标尚未完整验收：最重负载仍约5批/秒、完成P95约249ms；不是稳定30fps。
- 负载直接 feed，不是长期真实串口；斜线不是噪声/复杂波形。24卡测试有视口外懒绘制，不代表24张同时可见。
- 负载交互探针是 JS 往返/滚动、添加卡片与构建菜单，不是负载下的真实鼠标拖动/菜单点击。现有功能回归有 pointer 序列，但不能替代组合负载实测。
